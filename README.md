# Task Tracker

Консольная программа для учёта задач и дедлайнов.

## Возможности
Трекер умеет:
- Добавлять задачи с дедлайном.
- Отмечать задачи выполненными.
- Удалять задачи.
- Выбирать задачу для дальнейших действий.
- Отображать задачи.

## Особенности
- Проверка ввода: программа не падает на букве или несуществующем номере.
- Задачи сохраняются между запусками.
- Покрыт тестами.

## Запуск
```
git clone https://github.com/lonlix/task-tracker.git
cd task-tracker
python main.py
```

## Пример работы
```
     Меню выбора
1. Добавить задачу.
2. Показать все задачи.
3. Выбрать задачу.
0. Выход.
Ввод: 2
1. Task - Сдать лабу, Deadline: 20.10.2026, Done: False
2. Task - Подготовить доклад, Deadline: 25.10.2026, Done: True
```
