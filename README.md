# Task Tracker

Консольная программа для учёта задач и дедлайнов.

## Возможности
Трекер умеет:
- Добавлять задачи с дедлайном.
- Отмечать задачи выполненными.
- Удалять задачи.
- Выбирать задачу для дальнейших действий.
- Отображать задачи.

## Особенности
- Проверка ввода: программа не падает на букве или несуществующем номере.
- Задачи сохраняются между запусками.
- Покрыт тестами.

## Запуск
git clone https://github.com/lonlix/task-tracker.git
cd task-tracker
python main.py
